# Neovim Shortcuts

## Movement

- `h` `j` `k` `l` move
- `gg` top, `G` bottom
- `0` line start, `$` line end

## Search

- `/text` search forward
- `n` next match
- `N` previous match
- `<leader>fg` live grep

## Files

- `<leader>ff` find files
- `<leader>ex` file explorer
- `<leader>bn` next buffer
- `<leader>bp` previous buffer
- `<leader>sq` open this shortcut guide

## Harpoon

- `<leader>a` add current file
- `<leader>h` open Harpoon menu
- `<leader>hn` next Harpoon file
- `<leader>hp` previous Harpoon file
- `<leader>h1` select Harpoon file 1
- `<leader>h2` select Harpoon file 2
- `<leader>h3` select Harpoon file 3
- `<leader>h4` select Harpoon file 4

## Insert Mode

- `<C-h>` or `<C-BS>` delete previous word
- `<C-Space>` complete in completion menu
- `<CR>` confirm completion

## Terminal

- `<Esc><Esc>` leave terminal mode

## Python

- `<leader>rs` run current Python file
- `<leader>ru` run uvicorn
- `<leader>rt` run tests
- `<leader>f` format buffer
- `<leader>tt` open terminal output split

## LSP

- `gd` definition
- `gr` references
- `K` hover
- `<leader>rn` rename
- `<leader>ca` code action
- `[d` previous diagnostic
- `]d` next diagnostic
- `<leader>cd` line diagnostic
- `<leader>q` diagnostics list

## Built-in Vim

- `:Ex` open file explorer
- `:w` save
- `:q` quit
- `:wq` save and quit
- `:q!` quit without saving

## Surround / Wrap

- `ys` add surround
- `ds` delete surround
- `cs` change surround
